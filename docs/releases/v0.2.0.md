# cani v0.2.0

A Shobu SDK for Rust, C23, and C++26, supporting both handcrafted and neural bots.

## Highlights

- Canonical positions across 32 rule-preserving symmetries, with inverse move mappings for caches and training data.
- Compact 8 KiB legal-action masks, sparse action lists, and batch v1 tensor encoding in caller-owned buffers.
- Bounded, allocation-free perft diagnostics, with independent game-tree fixtures.
- An optional compact build profile for smaller native artifacts.
- A copyable 24-byte position, typed moves, legal generation, pushes, win detection, apply/undo, and deterministic position/state keys.
- Pluggable USP selectors with Rust, C23, and C++26 external-bot examples.
- Optional SSGF v1 records and game builders: RSSGF/BSSGF, player/event metadata, comments, undo, declared results, and validated replay.
- Buffered USP transport, fail-fast record validation, metadata/turn resource guards, and sanitizer-backed native integration tests.

The default rules SDK remains dependency-free. Canonicalization, masks, sparse actions, batch encoding, and perft allocate no heap memory in Rust/native value operations. Competitive evaluation, model runtimes, and playing policies remain supplied by bot implementations.

## Build and use

```text
cargo build --release
cargo build --release --features ssgf
cargo build --profile compact --lib --bin cani-usp
cargo run --release --example sdk
```

Include `include/cani.h` or `include/cani.hpp` for native integration. Define `CANI_WITH_SSGF` only when linking a library built with `--features ssgf`. See the [README](https://github.com/OpenShobu/cani/blob/v0.2.0/README.md), [bot data contracts](https://github.com/OpenShobu/cani/blob/v0.2.0/docs/bot-data-v1.md), and [SSGF v1 specification](https://github.com/OpenShobu/cani/blob/v0.2.0/docs/ssgf-v1.md).

## Compatibility and distribution

Existing USP 1.0 wire behavior, SFEN conventions, SSGF v1 bytes, neural v1 encodings, and symmetry IDs are retained. The crate is pre-1.0; public API compatibility should be reviewed when upgrading future minor versions. Position hashes can collide, so correctness-critical cache hits require full position comparison. Native callers must uphold the documented pointer ownership/lifetime contracts.

This is a source release with a verified Cargo package. The source archives include headers, examples, tests, documentation, LICENSE, and NOTICE. Native libraries can be built locally with the commands above. SSGF remains an optional Cargo feature.
